# Relay 项目手册

## 产品目标

**让人更快弄明白陌生的事，并能按需读深。**「快」以读者从首次接触，到能准确复述关键事实、关系和必要条件的时间衡量。

## 职责与边界

- **内容底座**负责采集和管理来源与原文，并管理阅读页的排版、渲染、导航和视图切换。
- **AI 加工**基于原文，为全文和各章节撰写简要与解读。**简要**交代足以准确复述的基本图景，**解读**补充机制、背景或适用条件。

## 文章风格

- **每个视图独立成稿。** 全文和章节的简要、解读都从读者关心的事情起笔，按理解这件事所需的顺序展开。
- **用具体经历让读者看懂。** 遇到抽象概念，优先让读者看到自己会怎么用、会遇到什么、结果有什么变化。
- **沿着作者的思路解释为什么。** 用「你」和读者说话，从作者要解决的问题出发，讲清功能、做法或取舍的来由。事实、因果和适用条件以原文为依据。

[写作约定与示例](../reading-lab/docs/content-style.md)

## 交接

**文章工作区**是交接点。内容底座提供 `source.md`，Agent 通过 Relay CLI 将简要和解读写入 `processed.json`。阅读页按全文或章节 ID 关联两者，供读者在简要、解读、原文之间切换。[内容契约](../reading-lab/docs/content-format.md) · [阅读前端](../reading/README.md)

会话、文章工作区和共享素材的设计见[加工蓝图](processing-blueprint.md)。
